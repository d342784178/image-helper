# Image Helper

提取页面图片并清洗到高清的油猴脚本（Tampermonkey）。

- Greasy Fork：https://greasyfork.org/zh-CN/scripts/598695-image-helper
- 安装链接（同步源）：https://raw.githubusercontent.com/d342784178/image-helper/main/image-helper.user.js

## 发布流程

1. 修改 `image-helper.user.js`，递增头部 `@version`
2. `git add image-helper.user.js && git commit -m "vX.Y.Z <说明>" && git push`
3. Greasy Fork 自动同步创建新版本（或在脚本管理页手动触发同步）
